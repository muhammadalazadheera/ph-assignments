Frequently Asked Question

What is the difference between var, let, and const?
var, let, and const are used to declare variables in javascript with some differences. One of the main differences is that var is function scoped and let and const are block scoped. var can be re-declared and updated but let and const can't be re-declared but can be updated. const is used to declare constants which can't be updated.
What is the difference between map(), forEach(), and filter()
map(), forEach(), and filter() are used to iterate over an array in javascript. map() returns a new array with the same length as the original array but with the modified elements. forEach() doesn't return anything but it is used to iterate over an array. filter() returns a new array with the elements that pass the condition.
What are arrow functions and how they are different from regular functions?
Arrow functions are a new way to write functions in javascript. They are more concise and have a shorter syntax than regular functions. Arrow functions don't have their own this and arguments but they inherit them from the parent scope. Arrow functions are not hoisted like regular functions.
How JavaScript Promises work?
Promises are used to handle asynchronous operations in javascript. A promise is an object that represents the eventual completion or failure of an asynchronous operation. Promises have three states: pending, fulfilled, and rejected. Promises are used to avoid callback hell and write cleaner code.
How closures work in JavaScript?
Closures are functions that have access to the outer function's scope even after the outer function has returned. Closures are used to create private variables and functions in javascript. Closures have access to the outer function's variables even after the outer function has finished executing.
