Question-1: What are the different ways to select an element in the DOM?

There are few javascript functions to select an element like getElementById, getElementByClassName, getElementByTagName, etc

Question-2: What is the difference between innerHTML, innerText, and textContent?

innerHTML gets or sets the HTML content inside an element. innerText gets or sets the visible text content of an element. And textContent gets or sets all text content, including hidden elements.

Question-3: What is event delegation in the DOM?

Event delegation is a technique to add event listener to children of a specific parent element. It helps to add event listener dynamically rather than adding event listener separately.

Question-4: What is event bubbling in the DOM?

Its a technique which fires all the event of the parents element up to body tag if a event listener of child is triggered.

Question-5: How do you create, add, and remove elements using JavaScript?

There a few javascript methods are available to to create, add and remove element like: createElement, appendChild, append, removeChild, remove etc
